# The Modern Kitchen (TheMeal)

Каталог кулинарных рецептов на данных [TheMealDB](https://www.themealdb.com/api.php): поиск блюд, фильтрация по категориям, странам и ингредиентам, детальная страница рецепта и список избранного.

🔗 **Демо:** [https://t0shich.github.io/TheMeal/](https://t0shich.github.io/TheMeal/)

## Возможности

- Поиск блюд по названию
- Каталог рецептов с фильтрацией по категориям, странам и ингредиентам
- Страница рецепта с ингредиентами и способом приготовления
- Избранное с сохранением между сессиями
- Адаптивный интерфейс с анимациями

## Стек

- React 19 + TypeScript
- Vite
- React Router
- TanStack Query
- Zustand (стейт + persist для избранного)
- Tailwind CSS
- Motion (анимации)

## Запуск локально

```bash
npm install
npm run dev
```
